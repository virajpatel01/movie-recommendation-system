Project Description:
------------------------------------------------------------
This assignment implements and compares five collaborative filtering methods 
to predict user ratings for movies using the ml-100k dataset.

The following methods are implemented in the provided notebook:
1. Method 1 – User Average Rating
2. Method 2 – Item Average Rating
3. Method 3 – User-based KNN Collaborative Filtering
4. Method 4 – Item-based KNN Collaborative Filtering
5. Method 5 – Hybrid of User and Item-based KNN Collaborative Filtering

Evaluation metrics used:  
- MAE (Mean Absolute Error)  
- RMSE (Root Mean Squared Error)
